The engine

Four guarantees,
not four features.

Everything below is a property of the math, provable before the robot moves.

01

Goal-based deployment

Define the end state. The engine derives kinematics, physics and path. No teaching pendant.

02

Certifiable safety

Clearance is a hard constraint in the optimisation — an auditable proof, not a learned behaviour.

03

Time-optimal motion

Smooth trajectories at the joint limits. Throughput without post-smoothing passes.

04

Vendor freedom

URDF in, motion out. Move a cell from Fanuc to UR to Kinova without rewriting it.

Comparison

How the engine differs

Sampling planners trade determinism for coverage. Learned planners trade certifiability for adaptability. We give up neither.

Property Hadeon Learned planners ROS / MoveIt
Safety logic Deterministic (SQP) Stochastic Sampling-based (OMPL)
Path quality Time-optimal, smooth Often erratic Needs post-smoothing
Setup Scan-to-plan, no code Data collection + training Developer integration
Certifiability High — explainable math Low — hard to validate Variable
Repeatability Bit-identical per input Seed-dependent Seed-dependent

About

We are Hadeon

Mission

Democratize robotic motion with a no-code engine that makes efficient, safe, robust autonomy available to any robot.

Vision

A world where deploying a robot is as seamless as hiring an expert. A machine that can navigate an orchard, pick ripe fruit and return it to the warehouse — provably safely.

The problem

The industry is stuck choosing between rigid manual programming and unpredictable AI. Neither scales.

01 · Bottleneck

Deployment is slow

Waypoint programming needs expensive experts and breaks when the environment shifts a centimetre.

02 · Fragility

The world isn't static

Faced with an unexpected obstacle, a traditional cell either crashes or freezes. Both cost the line.

03 · Certification

Black boxes don't pass audit

Probabilistic planners cannot guarantee safety, so they cannot clear strict industrial certification.
